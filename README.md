# InviteAura — Atrivarada & Renuka Shareable Invitation

This version contains both the InviteAura builder/preview and a real static public invitation page for the current wedding.

## Public invitation URL

After deploying to Netlify, the shareable invitation is:

`https://YOUR-SITE-NAME.netlify.app/i/atrivarada-renuka`

The exact hostname depends on the Netlify site name you choose.

## Deploy

1. Extract this ZIP.
2. Open Netlify Drop: https://app.netlify.com/drop
3. Drag the entire extracted folder into the drop area.
4. Open the generated Netlify URL followed by `/i/atrivarada-renuka`.
5. Test the link from a phone/incognito window before sharing.

## Important

This is a static single-invitation deployment. It does not yet provide customer accounts, database persistence, payments, or dynamic invitation publishing. The public invitation is specifically for Atrivarada & Renuka.
